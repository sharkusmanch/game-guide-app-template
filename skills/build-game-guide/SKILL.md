# Build a game guide

Use this reference workflow to turn a named game/run scope into a companion with evidence appropriate to its release level. Keep game facts, manual marks and confirmed achievement awards separate. The runnable synthetic starter remains useful while real-game evidence is unknown.

Start with [workflow](references/workflow.md) and fill [game brief](references/game-brief.md). Record claims and fixtures in the [evidence matrix](references/evidence-matrix.md); implement only the supported scope using the [adapter contract](references/adapter-contract.md).

At review, fill [review handoff](references/review-handoff.md). For publication use [public release](references/public-release.md); read [private release](references/private-release.md) only when private integration is in scope. These resources ship with the skill and resolve after link or copy installation. Keep filled operational records outside public source when they contain private inputs.

Apply existing user authorization and project policy. The references describe deliverables and evidence, and do not authorize publication, credentials access, infrastructure changes or delegation.
